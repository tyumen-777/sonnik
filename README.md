# Сонник — дневник сна малыша (PWA)

Браузерный аналог Napper: учёт дневного и ночного сна, прогноз следующего сна и статистика.
Работает офлайн и устанавливается на телефон как приложение. Данные хранятся только на устройстве (IndexedDB),
резервная копия — экспорт/импорт JSON в профиле.

## Запуск

```bash
npm install
npm run dev        # разработка, http://localhost:5173
npm run build      # продакшен-сборка в dist/ (с service worker)
npm run preview    # проверить сборку, http://localhost:4173
npm test           # юнит-тесты прогноза и статистики
```

Установка PWA и офлайн-режим работают только на https или localhost.

## Синхронизация между устройствами (Dexie Cloud)

Без настройки приложение работает локально. Чтобы включить синхронизацию и общий доступ для второго родителя:

1. Создайте облачную базу (спросит вашу почту и пришлёт код). Появятся `dexie-cloud.json` с адресом базы
   и `dexie-cloud.key` с секретом — его не публикуйте, он уже в `.gitignore`:
   ```bash
   npx dexie-cloud create
   ```
2. Разрешите адреса, с которых открывается приложение (локальные и боевой):
   ```bash
   npx dexie-cloud whitelist http://localhost:5173
   npx dexie-cloud whitelist http://localhost:4173
   ```
3. Скопируйте `.env.example` в `.env.local` и впишите адрес базы из `dexie-cloud.json` в `VITE_DEXIE_CLOUD_URL`,
   затем пересоберите приложение.

Как это работает:

- Вход по коду из письма — по желанию. Записи, сделанные до входа, при первом входе уходят в облако.
- В профиле → «Синхронизация» можно пригласить второго родителя по почте. Профиль ребёнка и все его сны
  переносятся в отдельную группу доступа; у приглашённого после входа появляется приглашение «Принять».
- Всё работает офлайн: изменения уходят в облако, когда появляется сеть.
- Если оба родителя нажали «Уснул» для одного сна, лишняя запись удаляется автоматически (остаётся более ранняя).
- Настройки (обычный подъём, начало ночи, активный ребёнок) — свои на каждом устройстве.
- Данные первой, чисто локальной версии переносятся в новую базу автоматически при первом запуске.

Email и записи сна хранятся на серверах Dexie Cloud. Для публичного продукта с пользователями из России учтите
требования 152-ФЗ о хранении персональных данных.

## Откуда нормы

- Сон за сутки: National Sleep Foundation (0–3 мес) и консенсус AASM 2016, одобренный AAP (4 мес – 5 лет).
- Безопасный сон: рекомендации AAP 2022.
- Окна бодрствования, число дневных снов, время отбоя — общепринятые ориентиры педиатров и сомнологов
  (в интерфейсе подписаны как «ориентир»).

Таблица — `src/norms/ageNorms.ts`.

## Как прогноз учится

`src/engine/predict.ts` → `personalize()`. Каждое окно бодрствования моделируется относительно возрастной нормы:

```
окно / норма = уровень[номер окна] + эффект_сна · (длина прошлого сна − обычная, ч)
                                   − эффект_утра · (насколько раньше обычного проснулся, ч)
```

- Записи за 14 дней, вес дня падает вдвое каждые 3 дня.
- Каждая оценка стартует с нормы или общепринятого допущения и сдвигается к данным ребёнка по мере их накопления,
  поэтому пара нетипичных дней не ломает прогноз.
- Отдельно запоминаются длина каждого дневного сна, обычные подъём и отбой. Если день сдвинулся и обычный сон
  не помещается до отбоя, план предлагает короткий сон или более ранний отбой.

Качество проверяется `src/engine/backtest.ts`: для каждого записанного сна восстанавливается прогноз, который
приложение дало бы в момент пробуждения, и сравнивается с реальностью. В приложении это блок «Точность прогноза»
на экране статистики. `src/engine/simulate.ts` генерирует журнал «ребёнка» с заданными привычками для тестов.

## Структура

- `src/db` — Dexie-схема и операции с данными
- `src/norms` — возрастные нормы и источники
- `src/engine` — чистые функции прогноза и статистики (+ тесты)
- `src/pages` — экраны: Сегодня, Журнал, Статистика, Профиль, Онбординг
- `src/components` — кнопка сна, таймлайн дня, карточка прогноза, редактор записи
